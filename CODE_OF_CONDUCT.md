# Code of Conduct

## Our commitment

This repository is maintained as an engineering portfolio and open-source learning project. We
welcome constructive, technically focused participation from people of all backgrounds.

## Expected behavior

Participants are expected to:

- Be respectful and professional.
- Focus feedback on the code, documentation, experiments, and engineering decisions.
- Explain disagreements with technical reasoning.
- Respect different levels of experience.
- Avoid harassment, personal attacks, discrimination, or deliberately disruptive behavior.

## Unacceptable behavior

Unacceptable behavior includes harassment, threats, discrimination, malicious disruption, and
publishing private information without permission.

## Reporting

For serious conduct concerns, please use the repository's GitHub contact/reporting mechanisms
rather than posting sensitive information publicly in an issue or discussion.

Project maintainers may remove comments, close discussions, or restrict participation when necessary
to keep the project constructive.

## Scope

This code of conduct applies to project issues, pull requests, discussions, reviews, and other
repository spaces maintained for this project.
