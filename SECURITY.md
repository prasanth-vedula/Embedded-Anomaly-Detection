# Security Policy

## Scope

This repository contains an embedded TinyML anomaly-detection portfolio implementation. Security
reports are welcome when they concern the repository, build pipeline, model artifact handling,
embedded runtime, CI workflow, or unsafe processing of untrusted inputs.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue.

Use the repository's private GitHub security reporting mechanism when available. If private reporting
is not enabled, open a minimal issue requesting a private reporting channel without including
sensitive exploit details.

Please include:

- A concise description.
- Affected file/component.
- Reproduction steps where safe.
- Expected and observed behavior.
- Relevant compiler/runtime information.

## Supported versions

Security fixes are normally applied to the latest maintained branch/release.

## Important limitation

This project is a portfolio/research implementation. Passing automated tests does not constitute a
security certification, functional-safety certification, or production security guarantee.
